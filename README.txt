余佳蓉个人作品集网站

打开方式：
1. 双击 index.html 即可打开；
2. 也可将整个 portfolio_final 文件夹部署到任意静态网站服务。

本次更新：
- 首页重构为洞洞板挂件导航，五个模块分别采用钥匙牌、透明文件夹、证件牌、技能吊牌与信封造型；
- 五个首页挂件支持悬浮反馈，并可跳转到关于、项目、经历、技能与联系板块；
- 全站视觉调整为黑白灰极简配色与浅灰渐变底色；
- 根据《作品集.docx》补全个人介绍、专业证书、奖项与央视报道链接；
- 根据《作品集图片.zip》重新校正图1-1至图1-35的素材与图注；
- 新增首屏代表作展示、项目案例叙事、工作经历与联系区块；
- 支持桌面与移动端响应式浏览；
- 作品图片支持点击放大、键盘打开与 Esc 关闭；
- 已压缩超大原图，降低首次打开时的等待时间。

文件说明：
- index.html：页面内容与结构
- style.css：页面视觉与响应式样式
- script.js：图片灯箱交互
- assets/：作品图片与个人肖像
